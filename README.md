# Softech
La empresa ficticia SofTech Solutions ha sido contratada por una clínica veterinaria que necesita un sistema de gestión integral. Sin embargo, el proyecto anterior fue un fracaso por las siguientes razones, no siguieron IEEE 830, no usaron priorización de requisitos, no usaron diagramas UML, no realizaron wireframes, y usaron Github de manera incorrecta.

En este proyecto se busca corregir estos errores y garantizar el éxito del nuevo proyecto, se adoptó un enfoque metodológico riguroso basado en estándares y buenas prácticas del desarrollo de software.

Se maneja planteamiento y organizacion de datos ya antes dados, se usa el metodo de Matriz Valor vs Complejidad para la priorizacion de requisitos y diagrama UML  para facilitar la estructura y el comportamiento del sistema.
